# LinguaSlice CLI

LinguaSlice turns a long spoken MP3 into a sentence-by-sentence listening exercise. It transcribes the recording with word timestamps, cuts each sentence from the original audio, and generates a local HTML player with the transcript and a Play button for every sentence.

## Requirements

- Node.js 20 or newer
- FFmpeg and FFprobe on `PATH`
- `OPENAI_API_KEY` in the root `.env`, unless reusing a saved transcription

The tool sends a temporary 16 kHz mono copy of the input to OpenAI for transcription. Sentence clips are cut from the original MP3. The compressed upload must not exceed 25 MB.

## Usage

Create a sentence player beside the source MP3:

```bash
node tools/linguaslice/cli.js create lesson.mp3
```

Choose an output folder and retain 0.25 seconds of surrounding silence:

```bash
node tools/linguaslice/cli.js create lesson.mp3 \
  --output downloads/lesson-player \
  --language en \
  --padding 0.25
```

Reuse a previous transcription without making another API request:

```bash
node tools/linguaslice/cli.js create lesson.mp3 \
  --output downloads/lesson-player-2 \
  --transcript-json downloads/lesson-player/transcription.json
```

Use `--force` to replace files generated by an earlier run. Other unrelated files in the output folder are preserved.

## Output

```text
lesson_sentences/
├── index.html
├── sentence_001.mp3
├── sentence_002.mp3
├── segments.json
├── transcript.txt
└── transcription.json
```

Open `index.html` in a browser and use the Play button beside each sentence.

## Sentence splitting

LinguaSlice uses punctuation in the full transcript to find language-aware sentence boundaries, then aligns those sentences with OpenAI's word timestamps. It retains a small amount of silence around each sentence without keeping long waiting periods. If the transcript and timestamped words cannot be aligned reliably, it stops instead of generating incorrectly timed clips.
